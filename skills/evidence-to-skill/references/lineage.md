# Lineage and attribution

`evidence-to-skill` is an original workflow and implementation by Aleksandr Shulgin.

It was informed by these projects:

- [AminBlg/SimpleEnglish](https://github.com/AminBlg/SimpleEnglish), MIT License — demonstrated that writing guidance can be expressed as explicit, mechanically checked constraints. This project uses a different goal and original rules; it does not copy the upstream rule set or linter.
- [virgiliojr94/book-to-skill](https://github.com/virgiliojr94/book-to-skill), MIT License — demonstrated progressive disclosure, topic indexing, and selective reading for large sources. This project replaces direct source-to-instruction conversion with an evidence ledger and blocking promotion gate; it does not copy upstream code or prose.
- [lubluniky/dale](https://github.com/lubluniky/dale), MPL-2.0 — informed the distinction between claimed, implemented, tested, integrated, and observed evidence. This project uses an independently written, smaller promotion contract and does not copy upstream code.

The MIT License in this repository applies only to this project's original material. Upstream projects retain their own copyrights and license terms.
